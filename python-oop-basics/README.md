# Python OOP Basics

Use this folder for Python fundamentals and object-oriented practice before moving into DSA solutions.

## Good fits

- Variables, loops, and functions
- Classes and objects
- Constructors and instance methods
- Inheritance and polymorphism
- Encapsulation and abstraction

## Suggested file names

- `class-basics.py`
- `constructor-practice.py`
- `inheritance-exercise.py`
- `polymorphism-demo.py`

## Starter template

Use [template.py](template.py) when you want a clean file to begin a new OOP exercise.
