# Dynamic Programming

Use this folder for memoization, tabulation, and optimization problems that benefit from overlapping subproblems.

## Good fits

- Knapsack-style choices
- Longest increasing subsequence
- Grid DP
- Partition DP
- State compression or memoization

## File naming idea

- `climbing-stairs.py`
- `house-robber.cpp`
- `edit-distance.java`
