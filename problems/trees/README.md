# Trees

Use this folder for binary tree, BST, traversal, recursion, and depth-first search problems.

## Good fits

- Preorder, inorder, postorder
- Level order traversal
- Lowest common ancestor
- Height and diameter problems
- BST search and validation

## File naming idea

- `binary-tree-inorder-traversal.py`
- `maximum-depth-of-binary-tree.cpp`
- `lowest-common-ancestor.java`
