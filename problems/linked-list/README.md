# Linked List

Use this folder for pointer-heavy problems that involve node traversal, reversal, merging, or cycle detection.

## Good fits

- Fast and slow pointers
- Reverse links
- Merge two lists
- Cycle detection
- Dummy head techniques

## File naming idea

- `reverse-linked-list.py`
- `merge-two-sorted-lists.cpp`
- `linked-list-cycle.java`
